# Requirements: PSA Code Sprint

**Defined:** 2026-08-17
**Core Value:** Identify the single highest-impact, non-trivial problem for an Agentic AI solution before committing to build.

## v1 Requirements

### Competition-Level

- [ ] **COMP-01**: Problem is identified within PSA Singapore's operational or supply chain ecosystem
- [ ] **COMP-02**: Solution addresses all 6 mandatory agentic capabilities (Event Ingestion, Reasoning, Tool Orchestration, Execution Trace, HITL Controls, Error Recovery)
- [ ] **COMP-03**: 10-slide presentation deck produced covering problem, baseline vs. agentic delta, architecture, decision logic, guardrails, and ROI
- [ ] **COMP-04**: 10-minute demo video showing running agent handling normal and edge-case inputs
- [ ] **COMP-05**: All submission assets complete by 2026-09-04

### Phase 1 — Operations & Systems Mapping

- [ ] **P1-01**: All 4 operational sectors researched with sector-specific topic depth (Berth & Marine; Container Yard & Internal Transport; Gate & External Haulage; Multimodal Logistics)
- [ ] **P1-02**: All 7 baseline digital systems mapped with capabilities, integrations, and data flows (CITOS, PORTNET, OptETruck, SmartBooking & iBOX, OptEModal, CALISTA, PSA BDP)
- [ ] **P1-03**: Physical, Information, and Decision flows mapped for each of the 4 sectors

### Phase 2 — Disruption Mining & Problem Bank

- [ ] **P2-01**: 10–15 candidate problems identified spanning all 4 sectors
- [ ] **P2-02**: Each problem documented with Trigger Event, Current Workaround, and Business Consequence
- [ ] **P2-03**: Focus on dynamic "something changed" scenarios where static rules fail (vessel delays, DG holds, equipment breakdowns, multi-party failures)

### Phase 3 — Evaluation & Selection

- [ ] **P3-01**: Every candidate problem scored against all 5 litmus-test criteria (Non-Deterministic, Multi-Tool, Multi-Step, Uncertainty Handling, Measurable ROI)
- [ ] **P3-02**: Target autonomy level defined and justified (Advisory / HITL / Supervised Autonomous)
- [ ] **P3-03**: Single Master Problem Charter locked with: problem selected, target user persona, and business impact equation

## Out of Scope

| Feature | Reason |
|---------|--------|

| Agent development (Phase 5) | Out of scope — separate build workspace |
| Demo video & pitch deck creation (Phase 6) | Out of scope — Phase 6 work |
